# ミセトモ v0.3

スパイラル産業向けSNS支援デモ。v1の写真中心の操作感と、v2のCTA・心理要素・売上シミュレーションを統合。

## 公開方針（ユーザー指定：2026-09-05）

今後のデモは、3日で失効するような一時公開サービスを使わない。利用者が追加の取得手続きをしなくても継続して使える本番URLを優先する。

共有先： https://ruu-first-app.vercel.app/misetomo/

このリポジトリのmainブランチから既存Vercelプロジェクトへ配信する。バージョン更新時も共有先は維持する。アカウント、サービス、公開設定の維持は必要であり、永久稼働を保証するという意味ではない。

index.html、kenshu/、menu-lab/など既存の他ページを変更しない。ミセトモの変更は原則misetomo/内で行う。

## 構造

index.htmlだけで動作する静的Webアプリ。外部ライブラリ・ビルド処理・外部画像への依存なし。

スタッフ画面：写真と情報 → 投稿本文とCTA → 人による確認 → PNG・投稿文保存。

経営者画面：仮定条件の試算 → 比較・3シナリオ → 実績の手入力 → 次回の検証案・テキスト報告。

写真はJPEG・PNG・WebP、1枚10MB以下、最大3枚。選択中の1枚を投稿カードに使う。Canvasで端末内合成し1080×1350 PNGとして保存する。写真そのものを生成AIで描き変える機能はない。

## 誤認を防ぐ仕様

外部AI・SNS・POS APIは未接続。文章・心理要素・改善案はルール／テンプレート方式。写真のAI解析、画像生成AI、自動投稿、実績の自動取得は未実装。

来店率はユーザーが設定する仮定値。CTAや心理要素の変更で率を自動的に上げない。シミュレーションの差を、投稿の因果効果・純増売上・保証値と表示しない。実績は未入力とゼロを区別し、確認売上を客単価から勝手に推計しない。

店長のチェックは同一端末上のデモ操作であり、認証済み承認者の署名や権限管理ではない。写真・本文・条件の変更で承認を解除する。

下書き・写真はブラウザのlocalStorage（キーmisetomo-v03）に保存。他ユーザーや他端末には同期されない。保存容量やブラウザ設定により保存できない場合は画面で通知する。
