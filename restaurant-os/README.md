# 飲食経営OS｜ルウ王子版 操作デモ

スパイラル産業向けの統合デモです。すべての店舗・仕入れ先・数値・試食結果は仮想事例です。既存アプリは変更せず、restaurant-os 以下に独立して追加しています。

## 入口

今日の営業／記録する／商品を育てる／全店を見る。右上の「体験ガイド」で一巡を試せます。

## 実際に動く部分

納品・検品、単位換算、販売入力、在庫、棚卸し差異、発注不足量、承認、店間移動の出庫と受取、外部購入の模擬手配と入荷、原価の比較、仕入れ候補比較、人による試食記録、厨房負荷の簡易試算、試験販売、追いルウ改善、旧版を残すレシピ改訂、他店への段階的な引継ぎ、担当者付きの仕事カード、写真の証拠添付、変更履歴、CSV・テキスト・JSONの書き出し。

数量と金額はルールで計算します。画面の解説は現在の状態から組み立てるルールベースであり、生成AIではありません。写真は証拠保存のみで、商品や数量を自動認識しません。

## 操作例

鶏肉40kgを納品確認 → チキン南蛮カレー100食を販売入力 → 廃棄1kg・実在庫17kgを棚卸し → 未確認差異2kgを表示 → 翌日120食に必要な24kgに対し、他店から3kgと外部購入4kgを手配する操作を体験。

商品開発では、候補選択 → 条件保存 → 試食・安全情報と再現性の確認 → 試作品入荷 → 小規模販売承認 → 結果記録 → 条件を一つ変えて再試作 → 正式版保存 → 他店で配信・確認・再現テスト・使用開始、の順で進みます。

## 保存と制限

保存は同じ端末・同じブラウザのlocalStorage内のみ。ブラウザデータ削除やプライベート閲覧の終了などで消える場合があります。実在の個人情報・機密・本番業務データは入力しないでください。設定から書き出しや初期化ができます。

生成AI API、実際のPOS・会計・SNS・発注送信、ログイン認証、サーバーDB、複数利用者の同期は未接続です。手配済み・承認などの状態はデモ内の状態であり、実取引は発生しません。表示の役割分けは本番用アクセス制御ではありません。衛生・アレルゲン等のチェックも本番の安全確認を代替しません。

金額は税抜の仮想値。原価と食材差引額の試算であり、人件費・家賃等を含む営業利益や税務上の評価額ではありません。厨房負荷は説明用の簡易試算です。

## 検証

ローカルChromiumで主要操作と不正入力、二重登録、差戻し、版管理、復元、文字列の無害化、画面幅360・390・768・1440pxを含む106項目を確認。ブラウザ制限によりローカル検証の保存にはインメモリアダプターを使用し、状態の保存と再読込を検証しています。本番の複数端末同期は実装していません。
