# 飲食経営OS｜総合版 / RUU EDITION

スパイラル産業向けの飲食店総合操作デモ。すべての店舗・スタッフ・予約・取引・商品価格は仮想です。旧 restaurant-os は変更せず、restaurant-suite に独立して追加しています。

## 18画面
今日のお店／予約・席管理／注文・会計／キッチン／仕込み／開閉店・衛生／在庫・棚卸し／仕入れ・発注／シフト・勤怠／引継ぎ・教育・設備／メニュー・原価／お客様の声／販促・SNS／日報・レジ締め／売上・経費／全店連携・ヘルプ／みんなの広場／設定・保存。

## はじめ方
右上の「使い方」で4つの体験コースを確認できます。上部の店舗名から10店舗を切り替えます。スマホは下部の「すべて」で全業務を開けます。

## つながる操作
1. 予約の来店受付から注文を登録。キッチンで着手→できあがり→提供。提供分をレシピに従って在庫減算。会計すると売上・日報・現金締めへ反映。会計後のテーブルは清掃を確認して空席へ戻ります。
2. 発注案→承認→模擬手配→検品→入庫。分納と請求差異に対応。仕込みでは原材料が減り、仕込み品が増えます。棚卸しと廃棄は履歴が残ります。
3. 全店ヘルプで食材やスタッフを依頼。店舗を切り替え、食材は承諾→出庫→受取、スタッフは本人確認済みの申出→受入店確認→シフト反映を体験。処理の重複を防止します。
4. ありがとう便、まかないラボ、全店の助け合いチャレンジ。投稿のいいねは1店舗1回で解除可能。アイデアから試作の仕事カードへ接続。安全確認や作業の速さを競わせず、人事評価には使いません。
5. メニュー価格・手順の改訂で全店に確認作業を作成。新しい注文や告知の下書きへ反映。古い注文の価格・原価記録は変更しません。

## 保存
同じ端末・同じブラウザのlocalStorage内のみ。複数人・複数端末の同期は未対応。ブラウザのデータ削除やプライベート閲覧で消える場合があります。保存できない環境では警告を表示し、ページを閉じると操作が消えます。別タブの更新を検知した場合は再読込を案内します。設定からCSV/JSONを出力できます。JSONの読込み機能はありません。旧デモとは保存領域を分離しています。

## 未接続・対象外
生成AI API、POS、決済端末、会計ソフト、実際の発注送信、SNS公開、配達配車、ログイン認証、店舗別の実アクセス制御、サーバーDB。音声文字起こし・写真認識・自動需要予測はありません。文章補助は固定テンプレートと現在の入力値を使い、AI生成と偽りません。

分割会計・返金・税率別処理・インボイス・給与計算などの本番要件は未対応。決済・打刻・予約・発注・承認はすべてデモ内の状態で、実取引は発生しません。画面の営業日と時刻は固定サンプルです。

レシピ原価は登録材料のみ。油・調味料・包材・全人件費・賃料などを完全には含みません。食材差引と記録経費の参考額は、営業利益・税務会計を示しません。設定された温度範囲なども仮想で、食品の安全性を判定しません。実際の顧客情報・従業員情報・機密を入力しないでください。
